##  Как генерировались данные?
Чтобы не вбивать 100 строк руками и база не выглядела пустой, я сделал DML-скрипт с максимальным рандомом:
* Видео берутся случайным образом из заранее заготовленного пула на 100 нормальных названий (поделены по темам).
* Даты загрузки, лайки и комменты раздаются через `random()`. 
* Лайки и подписки генерируются через `CROSS JOIN` с вероятностью ~40-60%, чтобы получился органичный разброс.
