# Лабораторная работа №3 — соединения таблиц

## Цель работы

Закрепить использование разных типов `JOIN` в PostgreSQL и получить сводный
отчёт по успеваемости студентов в разрезе учебных групп и курсов.

## Файлы

- [Исходные данные](data/data.sql) — DDL и тестовые записи для таблиц `group`,
	`student`, `course` и `course_listeners`.
- [SQL-запрос](sql/joins.sql) — итоговый запрос и
	пояснение выбранных соединений.

## Запуск

Скрипты рассчитаны на PostgreSQL. В пустой базе данных последовательно выполните
скрипт с данными, затем запрос лабораторной работы:

```sql
\i lab3/data/data.sql
\i lab3/sql/joins.sql
```

Либо запустите те же файлы через `psql`:

```bash
psql -d <имя_базы> -f lab3/data/data.sql
psql -d <имя_базы> -f lab3/sql/joins.sql
```

## Описание запроса

Запрос строит полную матрицу всех сочетаний учебных групп и курсов. Для этого
используется:

- `CROSS JOIN` между таблицами `group` и `course`, чтобы в результате были даже
	группы или курсы без студентов;
- `LEFT JOIN` с таблицами `student` и `course_listeners`, чтобы не потерять
	пустые группы и неназначенные курсы;
- `COUNT(cl.student_id)` для подсчёта только действительно записанных студентов;
- `AVG(cl.grade)` и `ROUND(..., 2)` для расчёта средней оценки с точностью до двух
	знаков после запятой.

## Результат

Каждая строка содержит:

| Поле | Описание |
| --- | --- |
| `group_code` | Код учебной группы |
| `course_name` | Название курса |
| `students_count` | Количество студентов группы, записанных на курс |
| `avg_grade` | Средняя оценка по курсу в этой группе |

Результат отсортирован по коду группы и названию курса. Для сочетаний без
записанных студентов количество равно `0`, а средняя оценка имеет значение
`NULL`.
